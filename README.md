AI-Powered Real-Time People Counting System

This project is a desktop-based web application that detects and counts people in real-time using computer vision and deep learning techniques.

It uses YOLOv8 for accurate human detection and OpenCV for video processing, while Streamlit provides a simple and interactive user interface.

Features
Real-time people detection using webcam/video
Accurate counting using YOLOv8 model
Live dashboard using Streamlit
Works for classroom, hall, and crowd monitoring
Easy to run and user-friendly interface
Technologies Used
Python
OpenCV
YOLOv8 (Ultralytics)
Streamlit
Use Cases
Classroom attendance monitoring
Crowd management
Security and surveillance
Event analytics
How to Run
python -m streamlit run project.py
